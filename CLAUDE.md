# CLAUDE.md

Children's language-learning game for a 5-year-old who can't read. The game is plain static HTML/JS: no framework, no build, no dependencies. Open `index.html` directly to run it. Optional accounts run on Vercel functions (`api/`, Node, CommonJS) with a Postgres database (Neon in production); see the README.

## Ground rules
- The child can't read, so **everything must be spoken**. Any new on-screen text the child needs gets narrated with `sayAll([...])` in the target language. On-screen text is a support for the grown-up, not the main channel.
- The narrator speaks **only the target language**, with one exception: the optional helper language (`save.ayuda`, set in the grown-up corner, on by default for a pack with `ayudaPorDefecto`). With it, `sayAll` follows each line with its spoken translation, taken from the other language files matched by position (`mapaTrad`/`traducir`). Text functions (`T.*`, microgame texts) record their translation as they run (`conTraduccion`). Syllables, phrase parts and anything marked `sinTrad` or `lento` aren't translated, so the child always repeats the target language. Never mix languages inside one string.
- **All child-facing strings live in `idiomas/<lang>.js` (`T.*`) or in `capitulos/<place>/<lang>.js`.** Never hard-code a phrase in `juego.js`. If you add a string, add it to every language file.
- The grown-up corner (`openParent()` in `juego.js`) is for the parent, never spoken. It follows the grown-up language chosen with the flags at its top (`uiLang`: en/es/fr/it, same as the account screens), so no language is ever mixed. Its texts are `rc_*` in `idiomas/rincon.js` (add every new one to the four languages); it is grouped in collapsible sections (child and languages, voice and play, account, this device, start over). There is no voice-recording UI any more: the narrator is the pre-generated Google voice.
- Languages to learn: es, fr, it, en, ar, ru (`IDIOMAS` in `capitulos.js`).
- Arabic is Gulf Arabic, spoken-first: every Arabic string is two-faced, `"latin|عربي"` (Latin transliteration for the grown-up to read, Arabic script that the voice reads). The screen shows the Latin face big with the script small underneath (`partirDobles` + `small.arab`), canvas text draws the Latin face, `speak()` says the Arabic face (`caraLatina`/`caraHablada`). Syllables are fully vowelled on the Arabic face; `{N}`, `{n}` and `*marks*` go on both faces (so always fill placeholders with `replaceAll`). Text functions in `ar.js` files build both faces with the `U()` helper. The child is addressed in the masculine; only standard Arabic letters (no چ). The pack sets `ayudaPorDefecto`, so a helper language is on unless the grown-up turns it off. The Arabic texts were written without a native speaker and need review by a Gulf Arabic speaker.
- Russian is two-faced like Arabic (`"latin|кириллица"`, big Latin transliteration for a grown-up who can't read Cyrillic, small Cyrillic under it; the voice reads the Cyrillic), but the Latin face is built automatically: the ru files are written in plain Cyrillic and wrapped with `ruDoble({...})` (`idiomas/ru.js` also has `ruTranslit`, `ruP(word)`/`ruF(phrase)` that cut syllables/parts automatically, and `ruU(...)` for the functions in the pack). `idiomas/ru.js` is loaded first (`cargarTodo`) because every ru file needs it. The child is never gendered in Russian (no past-tense "сделал/сделала": use present, plural or impersonal), and story lines with {N} are in the present tense because the character's gender varies. Time is said the Russian way (`reloj/ru.js`: «ровно три часа», «четверть пятого»). Intro part A for ru is `idiomas/nivel0-ru.js`; part B ru rows are in `scripts/datos/intro-b/ru/` (one Cyrillic cell per word, same order as the main files). The Russian texts were written without a native speaker and need review.
- Spanish is Rioplatense (vos, "tenés", "valija", "pasaje", "remera", "acá").
- Buttons stay disabled while the narrator talks. Wrap narration in `narrar(async () => ...)` inside modals.
- English is one of the languages to learn (`idiomas/en.js`, `capitulos/<place>/en.js`), and those same files are the English translations a grown-up sees when tapping a phrase (`data-en`) while the child learns another language. They are matched by position, so `en.js` must keep exactly the shape of the other text files. Never speak English while the child learns another language. Add English for every new string.
- Words need `silabas` (pronounced one by one, slowly) and phrases need `partes` (built up cumulatively). Syllables must be spelled so the target-language voice pronounces them correctly. A syllable that is a lone vowel gets read as a letter name ("é accent aigu"), and some voices spell out odd ones ("loj", "je") or anything with an accent added ("tó"), so each `idiomas/<lang>.js` has a `sonido` map that tells the voice how to say it. `voiceFor` avoids Edge's "Multilingual" voices, which guess the language of each utterance.
- Child-proof: big targets, arrow keys + mouse/touch, nothing destructive without the grown-up corner, ✕ buttons excluded from arrow navigation (`tabindex="-1"`).

## Architecture (juego.js)
- `registrarIdioma`, `registrarCapitulo`, `registrarTextos` are called by the data files. `buildCap(id, lang)` merges `base.js` + `<lang>.js` into the chapter object the engine uses.
- `T` is a proxy onto the current language pack's `t` object. `setLang(code)` rebuilds `CAP_LIST`.
- Voices: `voiceFor(code)` always picks a voice of that language and `speak()` waits for voices to load. Otherwise the browser falls back to English and mispronounces syllables.
- Save: `save` in localStorage key `aventuras-nico.v3`. Per-language chapter progress lives under `save.caps["<lang>:<place>"]`. Fish (`puntos`) and clothes (`armario`) are shared across languages.
- Rendering: canvas for the world/stories/flight (`drawWorld`, `drawScene`, `drawFlight`). `drawAnimal` draws all characters, and `drawHero` adds the outfit from the shop.
- Maps: each floor has its own size and shape (a space is outside the building; walls are drawn tile by tile), kept close to square so they fit a phone either way up. Below every U, D and L there must be floor. `resizeWorld()` leaves room for the touch arrows (below the map when upright, beside it when sideways).
- Phones: under 640px wide the stamp row becomes a counter, and under 520px tall the windows shrink so their buttons always fit. Check new screens at 390×844 and 844×390.
- Map legend and story-scene actor schema are documented at the top of `capitulos/aeropuerto/base.js`, with the extras (car/table tiles, restaurant backgrounds, `uniforme`, tip ending) at the top of `capitulos/restaurante/base.js`, and the clock ones (gear tile, `contar`, `buscar`, `numeros`, bells ending, `relojSVG`) at the top of `capitulos/reloj/base.js`, and the house ones (flowers/tree/sofa/toys tiles, home backgrounds, `final.icono`, video-call ending, `cara()` portraits) at the top of `capitulos/casa/base.js`, and the market ones (fruit-crate tile, `feria` background, shopping ending, `numeros` for the basket game) at the top of `capitulos/feria/base.js`, and the playground ones (sandpit tile, `plaza` background, hero/npc action `gesto`s drawn by `drawAnimal(..., {accion})`, swing/seesaw anims, Simon-says ending with `final.ordenes`) at the top of `capitulos/plaza/base.js`, and the doctor ones (exam-bed tile, `consultorio` background, `triste` gesto, white-coat uniform, teddy-hug ending, body-part game) at the top of `capitulos/doctor/base.js`, and the farm ones (hay-bale tile, `granja` background, overalls and straw-hat uniform, animal-parade ending with `final.desfile`/`sonidos`, feeding game) at the top of `capitulos/granja/base.js`, and the school ones (desk tile, `escuela` background, days-of-the-week ending with `final.dias`, shape-train game) at the top of `capitulos/escuela/base.js`, and the first-words ones (recap ending `final.palabras`, bubble game with `COLORES`) at the top of `capitulos/primeras/base.js`, and the beach ones (palm `y`, umbrella `n`, rock `i`, kelp `v` and coral `w` tiles, `agua:true` levels with light, bubbles and a swimming hero (`nada:true` in `drawAnimal`: body tilted forward, kicking legs, stroking arms; also used in `mar` scenes and the underwater parade), `portal:'<art>'` levels whose U/D is a water entrance instead of stairs (the entrance stays shut, `T.antesDelMar`, until every station on the beach floor has its stamp: `runMarCerrado`) (remember: `U` goes to the next floor number, `D` to the previous one), `=` sea tiles, `playa`/`mar` backgrounds, swimsuit + goggles-with-snorkel uniform, an underwater parade ending via `final.fondo:'mar'`, creature-finding then feeding game) at the top of `capitulos/playa/base.js`, and the party ones (balloon tile, `fiesta` background, party-hat uniform, `meses` counted at a station, birthday-song ending with every earlier place's final npc as guests, candles game) at the top of `capitulos/fiesta/base.js`. `drawReloj()` in `juego.js` draws a clock face on canvas.
- Spanish and Italian packs set `sinTilde`: `sonido()` strips the accent from a lone syllable before speaking it (some voices spell "tó" as letters).

- Places open in order, from home and first words up to harder topics (the order is `CAPITULOS` in capitulos.js; the week number comes from that position, not `base.num`): a place unlocks when every place before it is finished in the language being learned, or when the child already started it (`capPorOrden`, `capEmpezado`), unless a grown-up ticks "open all places" in the grown-up corner (`save.todoAbierto`). The admin can also lock places per child (`capAbierto`).

## Microgames (microjuegos.js)
- One per place, declared in `base.js` as `microjuego: {id, arte, precio, color}` with its texts in each `<lang>.js` (and `en.js`) under `microjuego`. `MICROJUEGOS[id](cap, M)` draws on `M.canvas`, puts buttons in `M.actions` and resolves when the round ends.
- Finishing a place (in any language) unlocks its game and gives one free play (`save.juegos[id].gratis`); after that each play costs `precio` fish. They are listed under the home screen's Games button.
- Keep them teaching something in the target language (the plane game says the color of each star, the pizza game names each ingredient), with no way to lose. Each one also needs a purely fun part, usually a free-play ending after the learning rounds:
  - clock: smash bouncing alarm clocks, counted aloud;
  - market: chop flying fruit, each one named;
  - kite: run while the kite climbs or drops to stars, with "up/down" called;
  - doctor: silly reactions per body part, then a tickle round;
  - farm: full-body animals that get fat and burp, plus free food throwing;
  - school: drive the train past shape stations;
  - beach: find the sea creature the narrator names, then a one-minute net-fishing round (tap the swimming creatures, each one named; arrows + Enter also work; texts `pescar`/`pescaFin`), then tap the water to feed them (they swim over, eat and blow bubbles);
  - party: play Happy Birthday note by note, or press ▶, changing speed, pitch and instrument.
- Shared helpers in microjuegos.js: `particulas()` for flying bits and `cartel()` for big outlined text.

## Conversations (charlas, `goCharlas`/`runCharla` in juego.js)
- Home → Chat. Each place can carry 4 conversations: `charlas: [{npc, arte, est, color}]` in `base.js` (`est` = the station whose stamp opens it, or `'final'` for finishing the place) and `charlas: [{titulo, chau, pasos}]` in every `<lang>.js` and `en.js`, matched by position (so the helper-language translation and the grown-up English tooltip work for free). A place without them just isn't listed; a language missing them hides them. All 12 places have their 4 conversations in every language each place has. Keep child lines gender-neutral where the language marks gender (fr/it/es), since the child can be a boy or a girl.
- A `paso` with `di` is the friend asking and the child answering; a `paso` without `di` is the child asking. Both have two `op`tions `{t: what the child says, r: the friend's reply}`. Use the pattern ask, ask-back, ask, ask-back (4 steps, 2 options each). Every option is valid: there is no way to lose.
- The narrator reads the friend's line and then each option (highlighted one by one); the child taps one, repeats it aloud and taps the star (same as stations). First completion of each conversation gives one biscuit (`save.charlas`, `save.galletitas`). Keep the child addressed neutrally where the language marks gender (no "cansado"), `{N}` is the child's name.

## Home path, building pictures, tour, Level 0
- Home is a winding path that runs top to bottom (`construirCamino` in juego.js): one stop per place, Level 0 first at the top. The top bar is sticky and shrinks (`.home.compact`) once scrolled, so language, shop, the `?` tour and the grown-up gear stay reachable. The road lights up to the current stop (first unfinished place; Level 0 only counts as current until the child starts any place). Backgrounds go meadow, river with bridge (before the 7th place), then snow towards the bottom.
- Each place has a picture in `escenas.js` (`ESCENAS[id] = {cielo, capas}`, 8 layers on a 200x200 canvas). Layer k appears when the child has k+1 stamps (the 8th when the place is finished); unearned layers show as a faint ghost (`.cp.off`). `escenaSVG(id, n, desde)` draws it, `runRevelar` shows the big picture after a new stamp, and `save.vistas[id]` remembers how many pieces were already seen so new ones animate when returning home. Adding a place: add its scene to `escenas.js` (keep the 8 layers) or the stop shows no picture.
- Three stars per stop, each with its own little icon so a child can read them: house = place finished, speech bubble = all 4 conversations done, joystick = its game played at least once (`save.juegos[id].jugado`). Level 0 stars are by word groups (3, 6, 8 groups).
- Level 0 (`idiomas/nivel0.js` words + intros, `idiomas/nivel0-arte.js` one picture per word, `goNivel0`/`runLeccion0`): about 75 words the game itself uses (what, where, very good, repeat...) in 8 groups. Each group is a lesson: a guide cat explains it (`intro`), every word is shown with its picture and practised syllable by syllable with the translation under it, then a "which one is...?" quiz, then a tick, confetti and 2 fish (a biscuit when all 8 are done). "All the words" is the old flat list for review. State in `save.nivel0`. A new word needs an entry in both files (same order) and its picture. Audio: word/syllable clips with `node scripts/audios.js --cap=nivel0`, the lesson lines (group names, intros, quiz questions, UI) with `--prompts`.
- On desktop widths (>=900px) the home top bar is always the thin version; on phones it shrinks once scrolled.
- Grown-up tour (`abrirTour`): runs once on first arrival at home (`save.tour`), from the `?` button on home and from the grown-up corner. Texts are `G.sNt/G.sNd` in `idiomas/grandes.js` (en/es/fr/it, flags on the first step). Add a step by adding it to `TOUR_PASOS` plus its two G strings in every language.

## Grown-up corner extras
- The report is its own page (`goInforme`, `informeCompletoHtml`, screen `#scr-informe`): 4-week bar chart with 7-day average, weekday pattern, places with stamps/chat/game icons, difficult words, other languages, plus the "computer voice" list: `sayAll` calls `anotarVozCompu` whenever it has no pre-recorded clip and falls back to the browser voice, counting lines in `save.vozCompu` (max 400, synced with the save) so they can be copied from the report and recorded with Google. Nothing in the client calls a TTS API on the fly; the only server-side TTS is the admin voice comparison. The child's name is spoken with the natural voice: `api/nombre.js` (GET `?n=&l=`, needs `GOOGLE_TTS_API_KEY`, 30 new names/hour/IP) generates it once per name and language, stores it in `nombres_voz` (or `.cache/nombres/` without a database), and the browser keeps it in the Cache API (`nombres-v1`). A line with the name (`{N}`) is played as three clips: the recorded piece before + the name + the piece after (`addN` in `scripts/audios.js` records both pieces of every `{N}` line: greetings, praise, conversations); `partesConNombre`/`hablarTexto` in `juego.js` join them. If the name or a piece is missing, it falls back to the recording of the line without the name (the home greeting is recorded nameless), then to the browser voice.
- Games: every game costs 1 fish (`precio:1` in `base.js`) after the first free play; `confirmarJuego` tells the child the price and asks, or says there aren't enough fish. The grown-up option "open all places" (`save.todoAbierto`) also opens every game (still paid).
- Entering it asks a sum (`puertaGrandes`) after the 1.5 s hold. It starts with a progress report (`informeHtml`): minutes per day for a week (`save.dias`, counted only while the child touches something), streak, places/stamps/conversations/Level 0 groups, how often the child said it out loud, and the words missed most (`save.fallos`, fed by `fallo()` in the quizzes). The corner and the report are always Spanish.
- "Listen to the child" (`save.escucha`, off by default): `starPress` opens the microphone only to measure whether there is voice before the star is tapped (nothing is recorded or sent); if there was none, the narrator asks once to say it out loud (`T.dilo`), then lets them through. Counts in `save.escuchas`.
- Accounts: creating one needs the privacy checkbox (`G.priv*`; the text needs a legal read before a public launch), the grown-up can delete the whole account and its data (`borrar_cuenta`), and sign-in / sign-up / recovery / password changes are throttled in the `intentos` table (`limitar`/`anotar` in `api/sesion.js`).
- Colours carry a mark (`PATRONES_COLOR` in `idiomas/nivel0-arte.js`, used by `marcaColor`/`blob`) so they don't depend on hue alone.

## Accounts (api/, servidor/, the NUBE section of juego.js)
- The game must keep working with no server (file:// or static hosting): `nubeInit()` turns online mode on only when `/api/sesion` answers JSON.
- The account screens (sign in / create account, "who's playing", the account part of the grown-up corner) are for grown-ups in the language they pick with the flags, English by default. Their texts live in `idiomas/grandes.js` (`G.*`, en/es/fr/it); add new ones to every language there. The server sends an error `codigo` and the client shows `G.err_<codigo>`. The admin page stays in Rioplatense Spanish. Child-facing lines (`T.cuentaDi`, `T.quienJuega`, `T.capCerrado`) live in the language files like everything else.
- Passwords: "forgot your password?" emails a one-hour link (`/?clave=<token>`, only its sha256 is stored in `recuperos`) through Resend (`servidor/correo.js`, needs `RESEND_API_KEY` + `MAIL_FROM`, optional `APP_URL`; locally the link is printed in the terminal). The admin can set a temporary password (`POST /api/admin?usuario=N`), and grown-ups can change theirs in the grown-up corner. Any password change bumps `usuarios.clave_ver`, which is in the session cookie, so old sessions stop working.
- Review (home → "¡A repasar!", `goRepaso` in juego.js): a word quiz mixing every word whose station has its stamp, in all places (`repasoPool`), and phrase practice that always picks among the least-practised phrases (`save.cuenta[id]`). Rewards: a fish per phrase, and a seahorse (`save.caballitos`) per word round and every 3 phrases. A seahorse is worth 2 fish: always check money with `riqueza()` and pay with `gastar(n)`.
- Drawings from every place share one namespace (`ART`): give new ones names no other place uses (`registrarCapitulo` warns in the console on a clash).
- The admin's **Abrir todo** (`alumnos.todo_abierto`, `pruebaTodo()` in juego.js) opens every place, game and story (`cuentoAbierto`), games free, for that child, overriding order and per-child locks. It is meant for testing.
- `persist()` also uploads the child's `save` (debounced, plus `sendBeacon` on page hide). Tables are created by `servidor/db.js` on first use; change the schema there with `IF NOT EXISTS`/`ALTER ... IF NOT EXISTS` so existing databases upgrade themselves.
- Voice comparison (`voces.html`, admin only, linked from admin.html): `api/voces.js` generates each sample line once with ElevenLabs or Google (`servidor/voces.js`, keys `ELEVENLABS_API_KEY` / `GOOGLE_TTS_API_KEY`) and keeps it in `voces_prueba`; the sample lines come from `scripts/voces-muestras.js`, shared with the terminal version `scripts/voces-prueba.js`.
- Local check: `npm install`, a Postgres in `.env`, `npm run dev`.

## Checking changes
- `npm test` = `node scripts/check.js` (syntax of every .js) + `node scripts/lint.js` (content). GitHub Actions runs both on every push (`.github/workflows/check.yml`).
- `scripts/lint.js` checks that every place has the same shape in all languages (es is the reference; `silabas`/`partes` may differ), no digits in spoken text, Arabic two-faced and the others never, `{n}` in the same spots, `{N}`/`{n}` on both Arabic faces, conversations with 4 steps and 2 options, every picture/scene (8 layers) exists, Level 0 lists and pictures line up, and that every conversation/Level 0 line has its recording. `--audio` also measures the syllable mp3s with ffmpeg. Fix what it reports before pushing; it exists because these slips were found by playing.
- `node scripts/check.js` (runs `node --check` on every .js file).
- `npm run cobertura -- --lang=es|en` measures how many of the 250 most frequent words (from film subtitles, `scripts/datos/`) the game teaches (child repeats), only says (narrator), or misses; the baseline and the remediation plan are in `docs/cobertura-top250.md`.
- The magic tower (`torre.js`, `goTorre`/`goLaberinto`) is the optional word explorer (sidebar button "La torre mágica", plus a one-time invitation `invitarTorre` after two finished places): a hall with 8 doors (themes, free order) and one small maze per theme (a random-but-fixed maze per theme, seeded in `laberintoDe`). `TEMAS` maps each theme to Intro groups (`gi` indices of `n0Grupos()`: 0-7 part A, 8-42 part B; when groups are added, update these lists). Each theme has 4 blue doors (required; `salasDe(i).req`, one room from each of 4 evenly spaced groups) and golden doors (the other rooms, shown 4 at a time, optional extras); when the 4 blue ones are done the floor is done (+2 fish, `save.torre`), all 8 = tower done (+1 biscuit). A door is one room of 3-5 words (`labSalas()`, `runLeccion0(gi, sala)`, `save.lab[<lang>:<group>:<from>]`); chests in dead ends give 1 fish once (`save.torreCofres`). The home stop's stars count finished floors. Walk with the arrows or by tapping (`camino` is a breadth-first search); the book button opens the old flat list (`goNivel0`) for review. Floor names are `T.temas` (8 strings per language, spoken when entering).
- Map editor `mapas.html` (linked from `admin.html`) edits the tower AND every place; "La Intro" is its own 10th map in `torre-mapas.js` (`TORRE_MAPAS[9]`: every corridor ends at one of the 4 blue doors, no golden doors or chests; the editor warns about dead ends); the tower's first floor keeps the golden extras. Cells are drawn with the real floor/wall colours of each map (places: `niveles[i].piso/pared`; tower: `torre-estilos.js`), doors as doors and objects as pictures. Tower maps live in `torre-mapas.js` (`window.TORRE_MAPAS`: hall + 8 floors, 11×9; floors use `1-4` blue doors, `5-8` golden doors, `*` chest, `D` stairs down, `P` hall start). The places' maps (`niveles[i].mapa` in `capitulos/<id>/base.js`) can be overridden without touching base.js: `mapas-lugares.js` (`window.MAPAS_LUGARES = {casa: [[rows of floor 0], ...]}`, applied by `registrarCapitulo`, loaded first in `cargarTodo`); the editor writes only the places you changed, can grow/shrink each floor, and checks (one `P`, every station once, `G`, floor under `U/D/L`, `U`/`D` pairs, a lift on every floor, everything reachable). "Probar" keeps a preview in localStorage (localhost only) and opens the game in that place (`?lugar=<id>`) or the tower (`?torre=hall|intro`); "Descargar" gives the file to commit. Object tiles are shared by places and tower: `b p a f r s c j o q h x y n i v w k e m` plus the new decorations `d` column, `g` trophy, `l` lamp, `t` rug (walkable), `u` sign, `z` mushroom (drawn in `drawTileObj`; the tower draws them as emoji in `DECO`). Lowercase letters left free: none; add new tiles by extending `drawTileObj`, `DECO` in `torre.js` and `OBJ` in `mapas.html`. The hero enters a tower floor next to its `D` and returns to the hall next to the theme's door.
- Level 0 (home path stop 0, `goIntro` in `torre.js`) is deliberately minimal: only the first tower floor, with its 4 blue doors (the basic game words: questions, well done, the game says, kind words; `TEMAS[0].req`) and no golden doors or chests; its stairs lead back home. Its 3 stars are 1, 3 and 4 doors (`introHechas`). Those 4 rooms are the same as the tower's first floor, so progress is shared. Everything else lives in the tower, so a new child never has to face it.
- Word of the day (`palabraDelDia`, `runPalabraDia`, card `.pdd` on top of the home path): one not-yet-learned Intro word per day (stable per day and language, `save.palabraDia`), 1 fish the first time each day, streak in `save.palabraRacha`. Learning it marks the word as done in `save.nivel0`.
- Intro (the old Level 0, `goNivel0`): part A = the 8 groups of game words (`idiomas/nivel0.js`), part B = ~35 more groups (`idiomas/nivel0b.js`): colours, animals, body, food, clothes, house, toys, vehicles, nature, feelings, actions, places, opposites, positions, and 7 groups of everyday phrases. `nivel0b.js` is GENERATED: edit the sources in `scripts/datos/intro-b/*.txt` (one line per word: picture | es | en | fr | it | ar, see the header of `scripts/gen-intro-b.js`) and run `npm run intro-b`; es/it syllables are automatic, en/fr/ar are written in the line. Pictures are emoji (`@#color` for colour swatches, `&body:x,y` and `&pos:in|out|on|under|near|far|left|right|front|back` for drawn ones). Then record with `node scripts/audios.js --cap=nivel0` and `--prompts`. `npm run cobertura:check` (also in CI) fails if the top-250 or the child-word list coverage drops; the child list is `scripts/datos/ninos.txt`.
- The Road ("El Camino", `supergame.js`, sidebar → Play, screen `#scr-camino`): a side-scrolling platformer. Arrows/WASD move, Space jumps, Shift (or the 💨 button) runs, E/Enter uses the tool (its button shows the current tool), Q or the 🔄 / header tool button switches it, double jump in the air (💦 water, 🫧 bubbles, 🎵 music); the touch pad `#camPad` does the same. Obstacles (`OBS`: fire, muddy pig, lion, bee) need one tool each; using it near an obstacle opens the speaking gate (the Intro word's picture, syllables, "your turn", star), and only then does the effect run and the obstacle clear into fish. A wrong tool just plays a hint (`T.caminoAgua/Burbujas/Musica`). Water tiles `~` switch the hero to the swimming sprite. Falling resets to the last flag; there is no way to lose. Items add up to fish: 🐟1 🍎2 🍒2 ⭐3 💎5 (`ITEMS`); `?` blocks and any platform give what is above them when hit from below. A chiptune loops per level (`CANCION`, MIDI notes; 🎵 button mutes, `save.caminoSilencio`). Finishing a level starts the next one, the last returns home. Every level has all three tools. Levels (`NIVELES`, built with `armar()` helpers) unlock by words learned (`UMBRALES`: Intro words learned + words with a stamp), or with open-all. The final flag asks for a phrase from `repasoPool()`. Progress `save.camino[id]={hecho,mejor}`, free to play (fish are collected, 5 for the first finish). Strings `T.camino*` in every language; recorded via `comunes` in `scripts/audios.js`.

## Audio (Google Chirp 3 HD Leda, pre-generated)
- `sayAll` plays a prerecorded mp3 when the exact text is in `audio/prompts.js` (`node scripts/audios.js --prompts`, needs `GOOGLE_TTS_API_KEY`), otherwise it falls back to the browser voice. The conversations (`charlas`: titles, goodbyes, every line and reply) and the chat UI strings are part of `--prompts`; lines containing `{N}` are skipped on purpose (the child's name changes) and use the browser voice.

- Audio indexes are per language: `audio/audio-<lang>.js` (ids of places' words, syllables, phrases) and `audio/prompts-<lang>.js` (text → mp3 of prompts and conversations), loaded on demand by `cargarAudio(lang)` for the learned and the helper language (`audio/manifest.json` is the combined record, not loaded by the browser). The generator rewrites them; never edit by hand.
- Characters have their own voices in conversations: each charla has `voz` in `base.js` (papa, mama, nina, mayor, chico, sabio, amable; mapped to Chirp 3 HD voices in `VOCES_PERSONAJE` in `scripts/audios.js`). The friend's lines (`di`, `r`, `chau`) are recorded with that voice and stored under the key `<voz>~<text>` in the prompts; the child's options and titles stay with the narrator (Leda). `sayAll` parts take `{t, voz}`; without a recording the browser voice is used with a different pitch (`TONO_VOZ`). To add a voice: add it to `VOCES_PERSONAJE` and `TONO_VOZ`.
- Hosting limits (checked Oct 2026, all free today): the repo is public on GitHub (~130 MB; 19k tracked files, 186 MB of audio). Git stores unchanged files once, but a re-recorded mp3 is a whole new blob (mp3 doesn't delta), so batch re-recordings (`--malas`, `--solo`) instead of regenerating everything. Vercel Hobby: 100 GB/month transfer, non-commercial use only, and CLI deploys are capped at 15,000 files / 100 MB (we exceed that, so deploy by git push, never `vercel deploy`). Tripwires: repo > 500 MB, Vercel usage > 70 GB/month, or a deploy failing on size or file count; first escape hatch is serving `audio/` from jsDelivr (`cdn.jsdelivr.net/gh/mistertach/learn@<tag>/audio/`) with `audio/` in `.vercelignore`, then Cloudflare R2 (10 GB free, no egress fees).
- The fish counter on every screen (`.pts`) opens `abrirCuentaPeces`: it counts the fish one by one (a seahorse = 2 fish, a biscuit = 3) and shows the sum.
- Offline: `sw.js` (service worker) + `manifest.webmanifest` make it installable; audio is cache-first, code is network-first. After re-recording audio with the same filenames, bump `AUDIO_VERSION` in `sw.js` and `AUDIO_VERSION_CLIENTE` in `juego.js` (otherwise devices keep the old clips). The grown-up corner has a button that downloads a language's audio for offline play. `vercel.json` sets the cache headers.
- Isolated syllables are the fragile part: the voice sometimes spells them out ("fe" as "efe", "ba" as "b-a"), says them in silence or clips them, and writing a digit makes it say "uno pececito" (write "un pececito", never "1 pececito"). `node scripts/audios.js --silabas [--solo=es,fr] [--malas]` regenerates syllables trying several spellings (IPA `<phoneme>`, plain text, the language's `sonido` hint...) and measures each result with ffmpeg (speech present, a single burst, sensible length), keeping the best; `--mudos` repairs word/phrase clips that came out silent. New syllables made by the normal generation go through the same check. Not verifiable by ear from here: after adding many syllables, listen to a few.
